# Nermine Melki Amdouni — Portfolio

A clean, professional GitHub Pages portfolio using the green / moss / cream / rose / teal palette from the provided reference image.

## Files

- `index.html` — portfolio content and structure
- `style.css` — responsive styling and color system
- `script.js` — mobile navigation + subtle scroll reveal
- `assets/Nermine_Melki_Amdouni_CV.pdf` — CV download

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload **all files and folders** from this package.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Save. GitHub will provide your `github.io` URL.

## Before publishing

Update the GitHub/LinkedIn details in `index.html` if you want to add more profiles. The current page uses the LinkedIn URL and email present in the CV.

The site intentionally uses no framework, build step, or backend, so it works directly as a GitHub Pages static site.
